## 2. 改 `appsettings.json`

```json
"App": {
  "Name": "報銷系統",
  "Tagline": "員工墊款、個人預支與零用金支付的申請、審核與核對。\n帳號由主管建立。"
}
```

兩處：`Name` 從 `ExpenseLite` 改成 `報銷系統`；`Tagline` 中間加一個 `\n`。

`\n` 會在登入頁副標渲染成換行——`.el-login-tagline` 有 `white-space:pre-line`。要調斷行位置就移動那個 `\n`，**不要放 `<br>`**。

## 這輪改了什麼（背景，不用執行）

**頁尾** — `_Layout` 新增 `<footer class="el-foot">`，顯示 `© 年份 系統名稱 · 資料使用說明`。年份用 `@DateTime.Now.Year`、名稱讀 `appsettings`，兩個都不寫死。中間的分隔點由 CSS 的 `::before` 生成，標記裡沒有「·」——之後增減頁尾項目不用改文字。

**登入頁密碼明碼切換** — 用文字「顯示／隱藏」而不是眼睛圖示（這套系統的介面語言就是襯線字，而且圖示常讓人分不清是現在的狀態還是按下去的結果）。切換鈕由腳本注入，view 只需包一層並標記。細節：按鈕是 `type="button"`（不然會送出表單）、切換後游標回到輸入框字尾、`aria-pressed` 跟著變。

**表單全站統一** — 八支表單都改成 label ＋ input 同一行，標籤欄寬統一 **76px**（最長標籤「確認預設密碼」6 字 @12px ≈ 72px）。原本 112px 與 76px 兩種寬度並存，本身就不一致。`.el-facts` 唯讀資訊列表也用同一個值，所以「不採用結清紀錄」那頁的上下兩塊仍然對齊。**不要再改窄**，會擠到標籤。

**金額欄不預填 0.00** — `asp-for` 綁非可空 `decimal` 時會把 0 印成 `0.00`，使用者得先刪掉才能打字。目前用 view 端判斷繞過。乾淨的做法是把 ViewModel 改成 `decimal?`，見 `HANDOFF.md` 的 B3 段。

**表格文字對齊** — 標題跟著它底下的資料對齊：文字欄靠左（中文從左讀起）、金額 `.num` 靠右（對齊個位數比大小）、筆數 `.count` 置中（靠右會貼到鄰欄看起來像同一組數字）。

## 驗收

- [ ] 每頁底部有 `© 2026 報銷系統 · 資料使用說明`，點得進去
- [ ] 內容很短的頁面（例如錯誤頁），頁尾仍貼在視窗底部而不是浮在中間
- [ ] 登入頁密碼欄右側有「顯示」，按下變「隱藏」且密碼變明碼
- [ ] 登入頁副標是兩行
- [ ] 功能列字標與瀏覽器標籤標題都是「報銷系統」
- [ ] 新增預支款的金額欄是空的，不是 `0.00`
- [ ] 表單的 label 與輸入框在同一行，各頁對齊位置一致
